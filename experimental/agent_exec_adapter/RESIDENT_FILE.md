## B1 corrected four-layer boundary

1. A local persisted intent, not published: blocks A enable/further controls and
history effects; S knows nothing and may continue always. No success ack or new
rid/republication on unknown. Operator diagnosis is the boundary.
2. Published, not accepted: still no global freeze. If original expected S gen
becomes stale, exact original request returns noop; never retarget a new rid to
modern head. Publication is not applied.
3. Accepted pending: S fixed whole-target tick gate and no-replay contract apply,
even if payload subsequently exits. Snapshot/done is not successful stop.
4. Exact original receipt plus held head and matching immutable old result with
real native identity/group convergence: only then stop final/ack, or history then explicit
replacement. Unknown/corruption/nonterminal done/failed prepare/start never
continues history or invents applied. Generic same-UID clients bypassing A are
outside A's agent-policy serialization promise; no new S framework is added.

Controls use original pending_reqs single policy entry. Local control stage is
saved before exchange. Shared exchange persists stable envelope/rid before send;
reopen only reads original publication/receipt, never resends absent intent or
changes rid. Same body returns original done, different body conflicts. Done is
operation return, not process completion. Validate node/kind/id/attempt/gen/
declaration digest/request and immutable result before projection. ownerEpoch,
snapshot mtime/top observedAt are not gen/liveness; pid.lastAliveAt uses actual
run observedAt and identical/older facts do not renew it.

Restart preserves history; clear uses original archive(best effort), backup(copy)
then truncate then weak _claim_origin before explicit new generation. Claim
still skips absent replica/nonreplica and swallows chown errors; no strengthened
claim or backup retention guarantee. Interrupted history cannot be replayed;
backup/truncate/claim exception preserves barrier, no compensation. New actual
request/gen/identity must be running before applied; restart done alone is not
running. Already-final stop noop, restart/clear rejected. Repeated/late controls
do not duplicate truncation or spawn. A can recover already-done missing ack only.

S always owns real exit0/nonzero replacements/backoff; A downtime does not stop
policy. Rejoin reads actual immutable intermediate results and marks whether A
observed a generation; never invents missing facts. Nonresident auto backoff
